# Course Repository Template

Use this folder as a starter structure for your course repository.

## Folder layout

- `lesson-01-setup-and-first-connection/`
- `lesson-02-create-tables-and-add-data/`
- `lesson-03-query-data-with-select/`
- `lesson-04-filter-sort-summarize/`
- `lesson-05-multiple-tables-and-joins/`
- `lesson-06-mini-project/`

Each lesson folder contains an `evidence.md` pro-forma to complete and commit.

## Minimum commit expectation per lesson

Make at least **2 commits** per lesson:

1. `lesson-0N: run starter script`
2. `lesson-0N: complete activity changes`

Optional third commit:

3. `lesson-0N: stretch challenge and evidence`

Use the same prefix style: `lesson-0N: <what you did>`.

## Evidence quality expectations

For each lesson evidence file:

- Include commit hashes for that lesson
- Include terminal output that shows your script ran
- Include your SQL/Python changes (not just copied starter code)
- Answer all understanding questions in your own words
- Record one error you hit and how you fixed it
